# HarmonyOS 贪吃蛇自由流转 Demo

本项目是一个 HarmonyOS ArkTS 贪吃蛇小游戏，并在游戏状态基础上实现了自由流转能力。

## 已实现功能

- Canvas 绘制贪吃蛇棋盘
- 分数统计
- 暂停/继续
- 重新开始
- 手机端方向按钮适配
- 自由流转时保存并恢复同一局游戏
- 手机和平板之间主动同步和读取游戏进度

## 多端互通说明

项目使用 HarmonyOS 分布式 KV 数据库保存共享游戏进度。设备 A 点击“同步到多端”后，会上传当前蛇身、食物、方向、分数和游戏状态；设备 B 点击“读取多端进度”后，可以恢复这份进度。两端应用可以同时保留运行，不需要迁移整个任务。

测试时，两台设备需要安装相同包名和签名的应用，并处于系统认可的可信设备关系中。建议登录同一华为账号，并开启 WLAN、蓝牙和多设备协同能力。

## 自由流转说明

游戏会保存以下状态：

- 蛇身坐标
- 食物坐标
- 当前方向
- 下一步方向
- 分数
- 暂停/结束状态

当设备 A 触发自由流转时，`EntryAbility.onContinue()` 会把当前游戏状态写入流转参数。设备 B 接续启动后，`EntryAbility.onCreate()` 或 `onNewWant()` 会取回这些参数，页面再恢复同一局游戏。

## 运行方式

1. 使用 DevEco Studio 打开本仓库。
2. 选择 `entry` 模块。
3. 连接 HarmonyOS 真机或模拟器。
4. 点击 Run 运行。

## 自由流转验收方式

1. 在设备 A 打开游戏并开始游玩。
2. 吃到食物或改变方向，让分数和蛇身状态发生变化。
3. 通过系统自由流转入口，将任务接续到设备 B。
4. 设备 B 打开后应恢复设备 A 上的蛇身、食物、方向、分数和游戏状态。
